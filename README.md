# Homey Dashboard

Project repository for a custom Docker-hosted dashboard for Homey Pro 2023.

Project documentation and implementation are maintained on the `phase_1_foundation` branch. See that branch for the current project foundation.


## Ontwikkeling

De vereisten en werkwijze voor de ontwikkelomgeving staan in [docs/08-ontwikkeling/README.md](docs/08-ontwikkeling/README.md). Docker Engine en Docker Compose zijn vereist om de applicatie tijdens ontwikkeling te bouwen en te draaien; installatie-instructies vallen buiten die documentatie.
