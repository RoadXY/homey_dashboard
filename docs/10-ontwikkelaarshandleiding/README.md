# Ontwikkelaarshandleiding

Deze map bevat de technische documentatie voor ontwikkelaars die het Homey Dashboard onderhouden of uitbreiden.

De documentatie beschrijft onder andere de architectuur, codepaden, API-contracten, foutafhandeling en implementatiekeuzes. Gebruikersgerichte uitleg staat in de [gebruikershandleiding](../09-gebruikershandleiding/README.md).

## Onderwerpen

- [Centrale dashboardfoutzone](dashboard-foutmeldingen.md)
- [Uitgebreide inventarisatie van Homey- en dashboardfouten](../03-dashboard/homey-foutmeldingen.md)

Bij documentatie over gedrag maken we onderscheid tussen:
- **Huidige implementatie:** wat de code vandaag daadwerkelijk doet.
- **Vastgelegd ontwerp:** het door de gebruiker gewenste gedrag.
- **Nog te implementeren:** onderdelen die nog niet in de code aanwezig zijn.

Maak dit onderscheid expliciet en presenteer een ontwerpbesluit nooit alsof het al gebouwd is.
