# Tablet en kiosk

## Doelapparaat
Samsung Galaxy Tab A SM-T515.

## Weergave
- Landscape.
- Responsive; geen aanname dat alleen één vaste resolutie wordt gebruikt.
- Scherm blijft 24/7 aan.
- Donker thema.
- Dashboardpagina zelf scrollt niet; meldingenpaneel mag scrollen.

## Kiosk
Fully Kiosk Browser is reeds aangeschaft en wordt gebruikt om de dashboardwebsite te tonen. De tablet is uitsluitend het scherm en bevat geen eigen dashboardlogica.

## Nog te bepalen
Exacte browserinstellingen, opstartgedrag, herstel na netwerkstoring, schermhelderheid, burn-in-maatregelen en watchdog/refreshbeleid.
